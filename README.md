## 🎯 Sobre o Repositório

Este repositório consolida minha jornada prática e teórica na disciplina de **Banco de Dados**. Mais do que armazenar códigos SQL, este espaço foi estruturado seguindo rigorosos padrões de **Design Profissional e Organização de Repositórios**, servindo como evidência das minhas competências em engenharia de dados, projeto de sistemas e resolução de problemas complexos.
